This was made in the unity game engine and can be played at https://mischievousgoose.itch.io/the-short-king

The Short King is a puzzle platformer game where you have to merge with aliens to grow bigger in order 
to fill up a set number of escape pods so you can save your civilisation. You play as a king called Blorp who
swears he is average height when one day an earthquake causes his civilians to scatter across the planet forcing him to step in.

This game was made for the jame gam game jam for teenagers (I'm 14).

Controls 

A/D - Move

Space - Jump

E - Merge with aliens

Q - Pause

R-Restart

Apart from these assets everything else was created my myself.
